# Safa Chat Widget

🚀 **Safa Chat Widget** is a modern, voice-enabled AI chat widget powered by ChatGPT technology — perfect for websites that want to add a friendly, interactive AI assistant for visitors.

---

## Features

- Text & voice chat with smooth typing animations  
- Responsive and mobile-friendly design  
- Secure API key authentication  
- Customizable styles and FAQs  
- Easy embedding with a single HTML snippet  
- Voice input (speech-to-text) and voice output (text-to-speech)  
- Built with Flutter, Riverpod, and OpenAI models under the hood  

---

### First Use

### How to Use

1. **Get Your API Key**  
   Sign up on our platform to receive a unique API key that authenticates your widget usage.

2. **Embed the Widget**  
   Copy and paste the following snippet in your website HTML where you want the widget to appear:

   ```html
   <safa-chat-widget api-key="YOUR_API_KEY_HERE"></safa-chat-widget>
   <script src="https://safa-chat-widget.onrender.com/SafaChatWidget.js" defer></script>
Customize
Add your FAQs and business data through your dashboard for tailored responses.
